1. Navigate to the relevant category folder
2. Open the .cpp or .cxx file for the specific problem
3. Compile using: `g++ filename.cpp -o output`
4. Run the executable: `./output`

- Executable files (marked as `x` or with `.exe`) are compiled binaries
