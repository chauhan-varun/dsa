# Data Structures and Algorithms (DSA)

This repository documents my journey learning and implementing various data structures and algorithms in C++.

## 📚 Repository Structure

### 1dArray (60+ implementations)
Array manipulation and algorithmic problems:
- **Searching & Finding**: Largest/smallest elements, duplicates, union operations
- **Subarrays**: Kadane's Algorithm, longest consecutive sequence, subarray with given sum/XOR
- **Two/Three/Four Sum Problems**: Using hashing and two-pointer approaches
- **Array Transformations**: Rotation, reversal, remove duplicates, Dutch National Flag Algorithm
- **Advanced Problems**: 
  - Trapping Rain Water
  - Moore's Voting Algorithm (Majority Element)
  - Next Permutation
  - Pascal's Triangle
  - Merge Overlapping Intervals
- **Mathematical**: Factorial, Fibonacci, GCD, palindrome, leap year
- **Vector Operations**: Vector basics, pointer operations, pass by reference/alias

### 2dArray (16+ implementations)

- **Basic Operations**: Matrix multiplication, transpose, sum of matrices
- **Transformations**: Rotate matrix by 90°, set matrix zeros
- **Traversals**: Spiral traversal (multiple approaches), circular spiral
- **Search**: Binary search in 2D matrix, find max element
- **Special Patterns**: Pascal's Triangle, max score binary matrix

### binarySearch (25+ implementations)

- **Basic Binary Search**: Standard binary search, linear search
- **Binary Search on Rotated Arrays**: Minimum in rotated array, search in rotated sorted array
- **Peak Finding**: Peak element, mountain array
- **Bounds & Special Searches**: Lower/upper bounds, missing positive integer
- **Advanced Problems**: Aggressive Cows, Book Allocation, Capacity to ship packages
